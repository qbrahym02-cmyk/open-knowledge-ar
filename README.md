# المعرفة المفتوحة — مكتبة عربية للمعرفة الحرة

موقعٌ ثابتُ البنية (لا يحتاج خادماً ولا نظام بناء) ينشر **كتباً كاملة مترجمةً إلى العربية** من مصادر في الملك العام أو بتراخيص مفتوحة حصراً: أدب، فلسفة، برمجة، قانون وسياسة، طب، اقتصاد، استراتيجية، وكتابة وتطوير الذات.

**الرابط:** <https://qbrahym02-cmyk.github.io/open-knowledge-ar/>

## البنية

```
index.html                  الفهرس الرئيسي (بحث + فلترة بالمجال)
about.html                  عن المشروع
data/books.json             الكتالوج الرسمي (ميتا كل كتاب)
book/<id>/index.html        صفحة تعريف كل كتاب
read/<id>/index.html        النص الكامل inline مع قارئ تفاعلي
downloads/<id>/<id>_ar.epub نسخة EPUB للتحميل
downloads/<id>/<id>_ar.md   نسخة Markdown للتحميل
covers/<id>.png             غلاف الكتاب
css/ · js/ · fonts/         الأمiri وIBM Plex Sans Arabic
```

## المنهجية

1. اختيار نص من الملك العام (Project Gutenberg وأمثاله) بعد التحقق من الرخصة.
2. تقسيم آلي للنص إلى مقاطع (~1500 كلمة) مع قاموس مصطلحات وأعلام موحّد لكل كتاب.
3. ترجمة آلية كاملة بنموذج الذكاء الاصطناعي GLM، مقطعاً مقطعاً.
4. تدقيق آلي للاكتمال ومطابقة البنية وخلوّ النص من بقايا إنجليزية أو دخائل لغوية.
5. توليد صفحات القراءة والتعريف وEPUB والأغلفة آلياً (pandoc + قوالب المشروع).

> الترجمات نسخٌ أولية عالية الجودة قابلة للاستخدام، ويُوصى بمراجعة لغوية بشرية قبل الطباعة أو الاستشهاد الأكاديمي.

## الرخص

- الكود البنيوي للموقع: مفتوح للاستخدام والتعديل.
- نصوص كل كتاب: حسب رخصته المذكورة في صفحته (معظمها ملك عام؛ وبعضها CC BY-NC / CC BY-NC-SA / Apache-2.0 كما هو موثّق في الكتالوج).

## الإضافة دفعة جديدة

أضف ميتا الكتب في `scripts/…/batchN.py`، ونفّذ الترجمة والتجميع والبناء، ثم ادفع إلى `main` — تعاد تلبية GitHub Pages تلقائياً.
